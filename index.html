Fundamentos DevOps

¿Qué es CI/CD?

La Integración Continua (CI) y el Despliegue Continuo (CD) constituyen la columna vertebral de la entrega moderna de software en la arquitectura de sistemas.

CI

Integración Continua (Continuous Integration)

Práctica de ingeniería donde los desarrolladores integran cambios de código con frecuencia en un repositorio compartido. Cada confirmación desencadena automáticamente la compilación del proyecto y la ejecución de pruebas para detectar errores de forma temprana.

  • Detección temprana de incompatibilidades y bugs
  • Compilación automatizada con TypeScript y Vite
  • Consistencia garantizada del código fuente
CD

Despliegue Continuo (Continuous Deployment)

Extensión de la integración continua donde los artefactos generados en la fase de construcción se transfieren y publican automáticamente en los entornos de producción o CDN global sin necesidad de procesos manuales propensos a error.

  • Publicación automatizada sin fricción ni demoras
  • Sincronización segura de artefactos con Amazon S3
  • Invalidación inmediata de caché en CloudFront
Stack Tecnológico

Tecnologías del Pipeline y Aplicación

Conjunto de herramientas de desarrollo frontend y servicios en la nube de Amazon Web Services que conforman la solución arquitectónica implementada.

Vite

Frontend Bundler

Herramienta de compilación ultrarrápida impulsada por ES modules nativos y Rollup. Compila y empaqueta el código TypeScript y estilos en la carpeta optimizada dist/.

Compilación & Minificación

GitHub Actions

CI/CD Orchestration

Plataforma de automatización que ejecuta el flujo de trabajo en cada push a hw-04. Gestiona la autenticación segura mediante OIDC sin exponer claves permanentes.

Pipeline & OIDC Auth

Amazon S3

Cloud Object Storage

Almacenamiento de alta durabilidad para alojar los archivos estáticos de la aplicación. Configurado en modo privado bloqueando acceso público directo, accesible únicamente por CloudFront.

Hosting Estático Seguro

AWS CloudFront

Global CDN

Red de entrega de contenido (CDN) distribuida globalmente con Origin Access Control (OAC). Distribuye el contenido con baja latencia, compresión HTTPS y caché inteligente en edge locations.

CDN + OAC + SSL
Automatización

Flujo de Ejecución del Pipeline

Pasos orquestados en el archivo .github/workflows/deploy.yml al confirmar cambios en el repositorio.

1

Checkout & Entorno

Descarga del repositorio y configuración de Node.js 20 LTS compatible.

actions/checkout@v4
2

Instalación Limpia

Instalación determinista de dependencias del proyecto.

npm ci
3

Build con Vite

Verificación de tipos con TypeScript y empaquetado optimizado en dist/.

npm run build
4

Autenticación OIDC

Asunción de rol IAM temporal mediante token federado de GitHub sin claves estáticas.

aws-actions/configure-aws-credentials@v4
5

Sincronización S3

Transferencia de archivos a Amazon S3 con eliminación de archivos obsoletos.

aws s3 sync dist/ s3://$BUCKET --delete
6

Invalidación CDN

Invalidación de caché para que los usuarios vean los cambios inmediatamente.

aws cloudfront create-invalidation /*
