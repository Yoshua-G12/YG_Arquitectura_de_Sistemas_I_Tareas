# Capturas de evidencia

Esta carpeta está preparada para las capturas reales de la entrega. En este entorno no se dispone de una herramienta de captura de navegador, por lo que no se agregan imágenes inventadas.

Para tomarlas manualmente:

1. Ejecuta `npm run dev` desde la raíz.
2. Abre `http://localhost:5173` y toma una captura donde aparezcan productos con los estados `Disponible`, `Stock bajo` o `Agotado`. Guárdala como `frontend-stock.png`.
3. Abre `http://localhost:3000/productos` y toma una captura del JSON que incluya `estadoStock`. Guárdala como `backend-json.png`.
4. Enlaza ambas imágenes en la sección de evidencias del README.
